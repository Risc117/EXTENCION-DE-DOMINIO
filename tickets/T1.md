# T1 · Arranque y tanque
Objetivo: crear el proyecto y ver el tanque en 3D con sus medidas, manejable con mouse.
Incluye:
- Proyecto Vite + React + TypeScript en esta carpeta, con git iniciado.
- Carpetas de src/ según CLAUDE.md, ESLint con eslint-plugin-boundaries, Vitest y Zustand.
- datos/homogeneizador.json validado con zod (demo: true si aún no hay medidas reales).
- El tanque armado por código desde ese JSON en src/unidades/homogeneizador/:
  muros, ingreso, salida y agitadores o difusores.
- Cámara con controles de órbita (girar y zoom con mouse o dedo).
- Aviso "Dato de ejemplo" cuando los datos son demo.
Fuera de alcance: agua, partículas, gestos.
Criterios de aceptación:
- [ ] npm run dev muestra el tanque y se gira y acerca con el mouse.
- [ ] Cambiar una medida en el JSON cambia el tanque, sin tocar código.
- [ ] Una prueba demuestra que ESLint falla si escena/ importa de simulacion/.
- [ ] lint, typecheck y test en verde.
