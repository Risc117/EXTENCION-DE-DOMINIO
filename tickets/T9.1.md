# T9.1 · Scripts del terreno con `npm run` y revisados por typecheck

Viene de: T9 (observación del qa-revisor).

Problema: `scripts/dxf-a-terreno/index.ts` y `planta.ts` dicen "npm run terreno" y "npm run planta", pero esos comandos no existen en `package.json`. Además `tsconfig.json` no incluye `scripts`, así que `npm run typecheck` no los revisa.

Incluye:
- Agregar a `package.json` los comandos `terreno` y `planta` (Node 24 ejecuta TypeScript directo).
- Agregar `scripts` al `include` de `tsconfig.json` y `allowImportingTsExtensions`; corregir los tipos que salgan.
- Comprobar que `npm run terreno` y `npm run planta` corren y dejan los JSON sin cambios.

Criterios de aceptación:
- [ ] `npm run terreno` y `npm run planta` funcionan.
- [ ] `npm run typecheck` revisa `scripts/`.
- [ ] lint, typecheck y test en verde.
