# T16.6 · Botón para ocultar el terreno

Viene de: petición del usuario (17 nov), antes de empezar T17.

Objetivo: poder ocultar el terreno para ver las unidades y las tuberías enterradas sin el suelo encima.

Incluye:
- Botón "Ocultar terreno" / "Mostrar terreno" en el panel del terreno (src/ui/PanelTerreno.tsx), con el estado terrenoVisible en src/estado/terreno.ts (empieza visible).
- Oculta todo el entorno del terreno: el suelo, las curvas de nivel, el muro de contención y la cota bajo el mouse (escena/terreno/index.tsx). Las unidades y las tuberías no cambian de lugar.
- Es independiente del botón de las curvas de nivel.

Criterios de aceptación:
- [x] El terreno empieza visible; el botón lo oculta y lo vuelve a mostrar (prueba en estado/terreno.test.ts).
- [x] El botón es independiente del de las curvas de nivel.
- [x] lint, typecheck y test en verde (566 pruebas).
- [ ] En el visor: con el terreno oculto se ven las tuberías enterradas y las unidades completas.

Notas:
- Al ocultar el terreno desaparece también la cota bajo el mouse (necesita el suelo para medirla).
