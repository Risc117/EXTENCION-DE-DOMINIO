# T5 · Pulido y publicación
Objetivo: dejar la web lista para mostrar y publicarla.
Incluye:
- Recorrido guiado de 4 o 5 vistas con texto que explica la función del homogeneizador.
- Pantalla inicial con las instrucciones de los gestos.
- Opción de calidad baja o alta (cantidad de partículas).
- Revisión en celular.
- npm run build y guía paso a paso para subir la carpeta dist a Netlify Drop.
- README corto: qué es, cómo correrlo, de dónde salen los datos.
Criterios de aceptación:
- [ ] El link HTTPS funciona en Chrome y Edge, con cámara y sin ella.
- [ ] Alguien que no lo vio entiende para qué sirve el tanque con el recorrido guiado.
- [ ] lint, typecheck y test en verde.
